How to Setup

  1. Configure this URL as a webhook endpoint in your Periskope account
  2. The webhook endpoint should be: https://your-deployment-url/webhook
  3. Select the ticket.created event
  4. Generate a signing key in Periskope
  5. Add the signing key to your Vercel environment variables as PERISKOPE_SIGNING_SECRET
